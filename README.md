## 📌 项目简介

本脚本在浏览器端（Tampermonkey）运行，模拟人工求职流程：

1. 打开 BOSS直聘搜索页（如搜索"AI Agent"）
2. 脚本自动逐条点击职位卡片 → 读取岗位信息
3. 生成打招呼语（**AI 生成 / 自定义 / 模板** 三种模式）
4. 自动点击「立即沟通」→ 跳转聊天页 → 自动发送
5. 发送成功后自动返回列表页，继续下一个职位
6. 达到每日上限或手动停止即结束

全程无需打开开发者工具、无需 Python 环境，**普通浏览器 + Tampermonkey 即可运行**。

## ⚙️ 配置说明

点击面板右上角 **「−」** 可折叠/展开；面板内有两个标签页。

### ⚙️ 投递配置页

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 今日计数 | 显示已投递数量 / 每日上限 | — |
| AI 开关 | 勾选后使用 AI 生成招呼语；取消则用自定义或模板 | ✅ 开启 |
| 每日上限 | 当天最多投递次数（1~200） | 30 |
| 间隔(s) | 每次投递之间的等待秒数（5~600） | 30 |
| 自定义招呼语 | 固定招呼语，留空则走 AI/模板；支持 `{title}` `{company}` | 空 |

> 💡 自定义招呼语优先级最高：**自定义 > AI 生成 > 第一条模板**。

### 🤖 AI 配置页

| 配置项 | 说明 |
|--------|------|
| API Key | 硅基流动密钥，**仅需配置一次**，自动保存；留空则不调用 AI，直接使用模板 |
| 模型选择 | 点击 **🔄 刷新列表** 从硅基流动 API **实时获取**全部文本模型（不写死）；支持关键词过滤，如输入 `Qwen` / `DeepSeek` |
| 招呼语模板 | 多条模板用 `---` 分隔，支持 `{title}` `{company}` 变量；清空恢复默认 |
| 我的技能 | 逗号分隔填写真实技能，**AI 只允许使用列表中的技能，严禁编造** |

**AI 生成时的硬性约束（写入 System Prompt）：**
- 只能使用「我的技能」中真实掌握的技能，严禁编造、夸大
- 写作风格参考所选模板
- 第一人称，120 字以内，直接输出

## 🔄 工作原理

```
┌─────────────────────────────────────────────────────────┐
│  职位列表页 (/web/geek/jobs)                             │
│                                                         │
│  点击职位卡片 → 读取 岗位/公司/JD → 生成招呼语            │
│        │                                                │
│        ▼ 点击「立即沟通」前保存会话到 GM 存储             │
│                                                         │
│  跳转到聊天页 (/web/geek/chat)                           │
│  找到输入框 → 填入招呼语 → 点击发送 → 校验成功            │
│  记录已投递 → 跳回列表页（全量刷新）                     │
│        │                                                │
│        ▼ 会话仍在有效期（15 分钟）内                      │
│  列表页自动恢复循环 → 跳过已投/失败 → 下一张卡片          │
└─────────────────────────────────────────────────────────┘
```

**关键设计：**

- **跨页面会话**：循环状态、当前职位、招呼语保存在 GM 存储中，页面跳转不丢失
- **防死循环**：跳回列表页使用全量刷新（`location.href`），而非 `history.back()`，避免浏览器 bfcache 复活旧上下文导致无限循环
- **发送校验**：发送后检查输入框是否被清空，未清空自动重试（最多 3 次）
- **停止即停**：每个等待点（点击卡片、AI 等待、发送重试）后都会检查停止标志，停止后不会重新写入运行状态
- **去重机制**：`bap_applied_日期` 记录已投职位，`bap_skip_日期` 记录发送失败职位

## 🖥️ 使用建议

1. **先小规模测试**：建议先设置「每日上限 = 5」跑一轮，确认发送正常后再调大
2. **间隔不宜过短**：过快投递可能触发平台风控，建议 ≥ 30 秒
3. **AI 生成前填写技能**：避免 AI 写出你不会的技能，造成面试翻车
4. **保持登录状态**：脚本运行期间请勿手动切换账号或退出登录
5. **运行中不要手动操作**：脚本会自动点击页面元素，运行期间请勿干预页面

## ❓ 常见问题（FAQ）

**Q1：面板没出现？**
检查是否在 `www.zhipin.com/web/geek/*` 页面（职位搜索页/聊天页）；刷新页面重试；确认 Tampermonkey 已启用脚本。

**Q2：点击开始后提示"请在职位列表页开始"？**
脚本只在职位搜索页运行，请打开如 `https://www.zhipin.com/web/geek/jobs?query=AI` 的页面。

**Q3：AI 生成失败 / 没反应？**
检查 AI 配置页是否已填写有效的 API Key；可先取消「AI」开关验证基础投递流程是否正常。

**Q4：发送失败怎么处理？**
脚本会自动重试 3 次；仍失败则记录到跳过名单（当天不再投该职位），并继续下一个职位，不会卡死。

**Q5：停止按钮点了没反应？**
最长等待 1~2 秒（当前步骤结束）即停止。若在聊天页点停止，会停留在聊天页不再跳转，手动返回列表页即可。

**Q6：更换浏览器/电脑后配置丢失？**
配置保存在 Tampermonkey 的 GM 存储中，与浏览器绑定。换设备需重新导入脚本并重新配置（可同步 Tampermonkey 账号）。

**Q7：脚本会不会泄露我的 API Key？**
API Key 仅保存在**本机浏览器**的 Tampermonkey 存储中，只在调用硅基流动 API 时发送，不会上传到任何第三方服务器。
